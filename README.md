# LegacyOne Wealth

A modern wealth solutions & financial products distribution firm website.

Built with **React 19 + TypeScript + Vite + Tailwind CSS**.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```
   Opens at http://localhost:3000

3. Production build:
   ```
   npm run build
   ```

## Project Structure

- `src/pages/` — page components
- `src/components/` — reusable UI components
- `src/data/content.ts` — site content (founders, solutions, values, etc.)
- `src/assets/images/` — bundled images and logos
- `public/` — static assets
